立体可见性分类器（纯 Go，无第三方依赖）。

- 每个实例分类为 双眼 / 仅左 / 仅右 / 双眼不可见，四类计数闭合到输入总数。
- 支持旋转包围盒（OBB）、层级变换（场景图）与跨近平面对象；分类保留每眼证据
  （穿越的平面）与首次失败原因（首先剔除它的平面）。
- 内置擦边、单眼遮挡、大对象跨眼等场景驱动轻量绘制列表，并与逐眼软件光栅
  覆盖结果对比，失配按 遮挡/亚像素/屏幕外/漏画 分类。

运行：

```
go run .    # 打印分类、计数闭合校验、绘制列表与光栅对比报告
go test .   # 回归测试（闭合性、单眼遮挡、近/远平面、视锥夹缝）
```
