# 分通道重投影校验

这个示例只使用 Go 标准库，用光线求交构造一个确定性场景，比较统一 warp 与主色、阴影、反射分通道重投影。

## 场景

- 移动灯：历史帧和当前帧使用不同灯位，阴影项必须按当前灯的阴影图重算。
- 镜面片：镜面历史按接收面深度与表面 ID 重定位，并与当前镜面项逐分量取最小值。
- 近墙遮挡：无深度统一 warp 会复用旧相机不可见的接收面样本；带深度和表面校验的方法拒绝这些样本。
- 统一约定：接收面与光照通道都使用相机前向线性深度、右手 pose 和相同的近远裁剪范围。

## 运行

```bash
go test ./...
go run ./cmd/reprojectcheck
```

CLI 输出颜色误差、反射误差、错误历史像素数和近墙遮挡样本数。反射亮度满足：

```text
separated reflection = min(history reflection, current reflection)
```

因此更亮的历史镜面采样不会抬高当前帧高光。
