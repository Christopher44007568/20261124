# stereowarp — 单目复用 + 右眼补绘（纯 Go 标准库）

左眼完整渲染后，右眼只复用仍有效的像素，其余区域按右眼视锥和真实深度补绘。
全程不引入任何第三方包，仅使用 Go 标准库（含 `image/png` 输出）。

## 目录结构

- `geom/` — 向量与针孔相机：投影 `Project`、反投影 `Unproject`，二者互逆。
- `raster/` — CPU 软件光栅化器：透视正确插值、z-buffer、透明片背到前混合、
  按瓦片（scissor）重绘与几何覆盖遮罩。
- `scene/` — 测试场景：房间五面墙、近杆（强视差）、中景杆、远色块、透明片。
- `warp/` — 核心复用补绘管线与单眼资源失效保护。
- `compare/` — 逐像素颜色/深度误差、MSE、PSNR、差异热力图。
- `cmd/stereowarp/` — 场景驱动：生成左眼图、复用补绘图、完整右眼参考图和差异图。

## 右眼复用补绘管线

1. **资源校验**：相机 epoch、深度 epoch、缓冲尺寸、深度合法性任一不符即拒绝，
   过期相机或过期深度绝不进入复用结果。
2. **前向 warp**：左眼像素用左相机反投影到世界点，再经右相机投影。透明片像素
   不参与复用（其颜色依赖新视角背后的内容）。
3. **视锥与可见性过滤**：目标视锥外、目标几何未覆盖（鬼影）、与目标真实深度
   不一致（遮挡消解）的样本全部丢弃。
4. **3×3 splat + 一像素膨胀**：填补亚像素空洞，膨胀深度同步外扩，不残留背景缝。
5. **分块补绘**：真正的去遮挡空洞与透明片覆盖像素构成 mask，仅重绘脏瓦片，
   mask 像素的颜色与深度重置后由右相机重新光栅化。

## 覆盖的相机场景

- `nominal`：纯水平瞳距偏移。
- `small-head-turn`：小幅转头（yaw/pitch）。
- `large-forward-move`：右眼前移 0.8 m，深度尺度剧烈变化。
- `edge-glance`：侧向注视，内容贴近视锥边缘。

## 单眼资源失效保护

过期相机 epoch、过期深度 epoch、缺失 color/depth、损坏深度、分辨率不匹配，
均返回明确的哨兵错误且不产出帧缓冲。

## 运行

```bash
go test ./...           # 单元 + 四场景质量阈值测试
go run ./cmd/stereowarp # 输出指标并写 PNG 到 artifacts/renders
```

每个场景产出四张图：`*_1_left.png`（首眼）、`*_2_reuse_repaint.png`（复用补绘）、
`*_3_right_reference.png`（完整右眼参考）、`*_4_diff.png`（差异热力图）。
