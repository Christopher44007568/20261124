# pupilsim

瞳孔在镜片后方移动时，虚拟图像位置随注视方向漂移的仿真与补偿对比。
纯 Go 标准库实现，不依赖任何图形 SDK（PNG 图表由 `image/png` 直接绘制）。

## 模型

- 镜片：Prentice 规则，棱镜量 P[Δ] = 偏心 c[cm] × 光度 F[D]，
  偏折角 atan(P/100)。默认 50 D、虚像距 1.5 m（1 mm 瞳孔偏心 ≈ 171.6 角分）。
- 合成视线（`internal/gaze`）：注视漂移 + 微扫视的自然眼动、
  smoothstep 剖面的快速扫视、回中序列、随机突发式追踪丢失；
  测量值叠加高斯噪声，丢失帧无效。
- 三种补偿（`internal/optics`）：
  - `fixed`：固定投影，不做任何补偿；
  - `per-eye`：逐眼直接使用当帧测量偏移，丢失时回零（会跳变）；
  - `smoothed`：一阶低通 + 摆率限制，丢失时保持并缓慢回零（不跳变）。

## 场景与指标

场景（`internal/sim`）：`natural` 自然眼动、`saccade` 快速扫视、
`recenter` 离开并回到中心、`loss` 高频追踪丢失。

每帧指标：左右眼角漂移（角分）、双目视差（角分）、虚像面角点位移（mm）、
漂移帧间跳变、补偿偏移帧间跳变（区分丢失帧）。

## 运行

```sh
go run ./cmd/pupilsim          # 输出到 artifacts/
go test ./...
```

产物：`artifacts/<场景>_<模式>.csv`（逐帧指标）、`.png`（漂移/视差/丢失区间图）、
`summary.csv`（汇总表，同时打印到 stdout）。

## 结论（默认参数）

- 固定投影：扫视时角点漂移达数百角分，完全不可用。
- 逐眼 offset：RMS 漂移大幅降低，但追踪丢失回零造成高达 ~800 角分的
  补偿跳变，且单眼丢失时双目视差急剧恶化。
- 平滑补偿：RMS 与逐眼相当，丢失帧的补偿跳变被摆率限制约束在
  ~100 角分以内，无突然跳变；代价是扫视期间存在短暂滞后。
