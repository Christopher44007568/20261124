# offaxis：每眼离轴投影与软件光栅化对照

仅依赖 Go 标准库（`math`、`errors`、`fmt`、`strings`、`os`、`testing`），无第三方包。

## 要解决的问题

左右眼 FOV 不对称时，平移视口只能改变对称投影的 NDC 缩放/平移，无法表达
`glFrustum` 第三列中的离轴项 `(r+l)/(r-l)`、`(t+b)/(t-b)`。本项目直接从任意
`left/right/bottom/top/near/far` 边界构建每眼投影矩阵，并用三条相互独立的链路
互相验证：

- 解析视锥：由边界直接推导六个内朝半空间平面，做点的内/外/边界判定；
- 齐次裁剪标记：从投影矩阵做 Gribb-Hartmann 平面提取与 clip-space 边缘位标记；
- 软件光栅器：Sutherland-Hodgman 齐次裁剪 + 透视校正深度 + 左上填充规则。

## 目录

- `pkg/offaxis`：可复用库（矩阵、视锥、平面、裁剪、光栅器、三方对照）；
- `cmd/offaxis-demo`：命令行演示，输出矩阵、ASCII 边缘标记网格、深度缓存与对账结果。

## 运行

```sh
go test ./...
go run ./cmd/offaxis-demo
```

## 覆盖的几何情形

- 任意不对称的左右上下边界（离轴），每眼独立矩阵；
- 单眼近裁面穿透：顶点位于相机后方（`w < 0`）时先剔除整图元，再对真正的近平面
  `w + z >= 0` 裁剪，避免在相机平面 `w = 0` 产生无穷 NDC；
- 宽高比变化：宽视锥与非方形视口，透视校正深度与解析 `1/z` 深度对账；
- 视锥角点退化：`left == right` 或 `bottom == top` 直接拒绝。

## 拒绝规则（哨兵错误）

- `ErrInvalidDepth`：near/far 非正或非有限；
- `ErrReversedDepth`：`near >= far`（含近远颠倒与相等）；
- `ErrDegenerate`：横向开口面积为零；
- `ErrCenterRay`：矩阵无法把视锥中心射线映射到 NDC 原点（含篡改或仅视口平移近似），
  或双眼中心射线在头空间不平行（toe-in 汇聚）。

## 三方对照如何对账

探针网格在固定眼空间深度上按 NDC 反投影采样，逐点比较 clip 边缘位与解析平面位，
并比较矩阵窗口深度与解析 `1/z` 深度；光栅化像素再用各自真实深度反投影回眼空间，
与解析平面、深度公式核对。演示末尾的 `RESULT` 与进程退出码反映全部对账是否通过。
