# 曲面层标记映射：平面 / 圆柱 / 等距柱状球面

同一个程序化标记分别贴到平面、圆柱、等距柱状球面三层上，用 Go 标准库
（`math`、`image`、`image/png`）做逐像素逆映射渲染，输出双眼立体结果，
覆盖圆柱接缝、球面极点与非均匀缩放，并验证深度排序与包裹采样。

## 设计要点

- 不用平面四角插值。每个像素从左右相机发出针孔射线，与图层做解析求交，
  再把交点逆映射成参数坐标 `(U,V)`，在参数空间采样。见 `internal/geom/surface.go`。
- 圆柱绕竖直 Y 轴，正面经线就是 `U=0/1` 接缝；球面用等距柱状投影，
  极点在 Y 轴，经度环绕、纬度在两极钳制。
- 包裹采样按“一个周期内的最短环绕距离”判定归属，标记足迹窄于一个周期时
  只会命中一次，从根上避免接缝处的标签双影。见 `internal/tex/wrap.go`。
- 三种轴模式：`WrapRepeat`（经度）、`WrapClamp`（平面/圆柱纵向，越界透明）、
  `WrapClampPaint`（球面极边，冻结边缘纹素但不向整圈涂抹）。
- 深度排序按每条射线的最近命中逐像素决定；同时用一个固定画家顺序
  （球 > 柱 > 面，无视距离）生成对照，差异即为排序错误图。
- 双眼视差按针孔关系 `d = f * baseline / depth` 计算并做伪彩编码，近面位移大。
- `quadwarp_cylinder_wrong.png` 是故意保留的错误范例：用平面四角双线性 UV
  扭曲圆柱，曲率被压平且接缝标记重复成两份。

## 目录

- `main.go`：场景、双眼相机与全部 PNG 输出。
- `internal/geom`：向量、针孔相机、平面/圆柱/球面求交与 UV 逆映射。
- `internal/tex`：标记纹理、双线性采样、三种包裹模式。
- `internal/render`：图层涂装、逐像素合成、排序错误图、视差图、四角插值反例。

## 运行

```sh
go test ./...
go run .
```

## 输出（artifacts/）

- `ref_plane.png` / `ref_cylinder.png` / `ref_sphere.png`：单层双眼参考。
- `overlay_sorted.png`：三层按真实最近距离排序的双眼叠加结果。
- `ordering_error.png`：红色为固定画家顺序与真实最近面不一致的像素。
- `disparity.png`：双眼水平视差伪彩图，右侧色条为近（红）到远（蓝）。
- `quadwarp_cylinder_wrong.png`：平面四角插值的错误对照，展示双影与曲率失真。
