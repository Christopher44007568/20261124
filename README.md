# 单眼空洞的双目重投影补洞实验

纯 Go 标准库实现，不依赖图形 SDK、OpenGL、CUDA 或第三方包。项目构造一套可重复的合成双目场景，比较目标眼原图、跨眼守卫补洞、禁止跨眼补洞和完整参考。

## 为什么不能同屏坐标直接复制

左右眼像素不是一一对应的。对源眼像素 `(x_s, y_s)` 和相机深度 `d_s`：

```text
P_world = Unproject_source(x_s, y_s, d_s)
(x_t, y_t, d_t) = Project_target(P_world)
```

只有重投影后的 `(x_t, y_t)` 才允许写入目标眼。实现采用前向 warp 加最近深度选择，等价于在有目标深度时做反向查找，但不需要对每个空洞像素盲目搜索。

直接复制同一个屏幕坐标会把源眼的视差、遮挡和高光一起搬错。默认场景的平均水平视差约为 35 px，错误一目了然。

## 场景与四类样本

`NewDemoScene` 用四边形光线追踪生成左右眼图像，同时保留深度、物体 ID、类别和追踪可信度：

- `wall-corner`：位于两眼中心之间的单面侧壁，只有目标左眼能看到；源眼看到其后面的背景。
- `specular-only`：朝向目标眼的银色高光边，源眼只能采样到背景。
- `transparent-only`：半透明膜的颜色混入背景，深度有歧义，追踪标记为不可信。
- `shared-surface`：两眼都可见的蓝色棋盘表面，可被正确重投影补齐。
- `asymmetric-mask`：目标眼看到棋盘、源眼被半透明膜挡住的不对称区域。

空洞在目标眼图像中置黑，但位置、深度、ID 和追踪状态仍由合成器保留，用于验证拒绝原因。

## 守卫条件

`CrossEyeFill` 只接受同时满足以下条件的源样本：

1. 源像素追踪有效，且不是透明层歧义像素。
2. 源像素与目标像素属于同一物体，拒绝轮廓/遮罩错配。
3. 重投影深度与目标深度的差不超过 `0.025 + 0.012 * depth`。
4. 目标像素的单眼追踪可信。
5. 3x3 源邻域中至少有 5 个像素映射到附近且深度一致，拒绝孤立或不对称遮罩。

拒绝原因分别为 `mask_no_overlap`、`mask_surface_mismatch`、`source_tracking_invalid`、`depth_mismatch`、`target_tracking_invalid` 和 `mask_asymmetric_support`。

## 运行

```bash
go test ./...
go run ./cmd/stereoholes -out out
```

可选参数：`-width`、`-height`、`-baseline`、`-out`。

输出：

- `out/01-original.png`：目标眼原图，空洞为黑。
- `out/02-cross-eye-guarded.png`：跨眼重投影 + 守卫补洞。
- `out/03-no-cross-eye.png`：只使用目标眼边界像素的最近邻填充。
- `out/04-reference.png`：完整目标眼参考。
- `out/05-naive-unguarded.png`：重投影但跳过所有守卫的诊断基线。
- `out/06-guard-map.png`：绿色为接受，蓝色为表面 ID 不一致，粉色为源追踪失效，灰色为无重投影覆盖，红色为深度不一致，黄色为目标追踪失效，青色为邻域支持不足。
- `out/comparison.png`：四路 2x2 对照图。
- `out/report.json`：全局与分区指标。

## 默认结果

在 `480x320`、基线 `0.36` 下：

| 模式 | 已填 / 空洞 | 平均误差 | 已填像素重影率 |
| --- | ---: | ---: | ---: |
| 原始眼 | 0 / 6951 | 0.2760 | 0% |
| 跨眼守卫 | 1191 / 6951 | 0.2333 | 0% |
| 禁止跨眼 | 6951 / 6951 | 0.0485 | 14% |
| 完整参考 | 6951 / 6951 | 0.0000 | 0% |
| 无守卫诊断 | 6951 / 6951 | 0.0516 | 13% |

守卫版保留未验证空洞，因而填充率不高，但所有被接受的像素都没有超过重影阈值。无守卫版看起来“填满”，却把单眼墙角、高光边和透明层错搬进目标眼。禁止跨眼版不会产生明显的跨眼重影，但在高频边缘和单眼特征处会变糊。

## 代码结构

- `camera.go`：平行双目针孔相机、投影与反投影。
- `scene.go`、`render.go`：场景、透明混合、深度与追踪元数据。
- `fill.go`：前向重投影、守卫补洞、同眼填充、无守卫诊断。
- `holes.go`、`analysis.go`：空洞分区和双眼可见性分析。
- `metrics.go`：填充率、误差和重影率。
- `montage.go`、`image.go`：纯标准库 PNG 与对照图输出。
