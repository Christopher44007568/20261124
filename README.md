# IPD 同步立体投影实验

这个程序只使用 Go 标准库。它把瞳距从 55 mm 增加到 72 mm 时，眼矩阵、
透视投影、视差和遮挡作为同一套几何的派生量一起改变，再从左右眼图像恢复
深度，并用解析射线交点核对。

## 运行

```bash
go run ./cmd/ipdscene -out artifacts
go test ./...
```

第一项命令重新生成 `artifacts/` 中的左右眼图、深度图和 `report.json`。

## 场景

世界坐标为毫米，`+X` 向右、`+Y` 向上、相机朝 `+Z` 看。渲染尺寸为
480×360，焦距 `f = 520 px`。正确相机左右眼分别位于
`x = ±IPD/2`，主点均为 `(240, 180)`。

场景包含：

- 后墙 `Z = 1500 mm` 上的毫米标尺：10 mm 短刻度、50 mm 红刻度，
  每 100 mm 带数字。
- 球心 `(-170, 10, 990)`、半径 `115 mm` 的绿色球体。
- `Z = 758 mm` 的橙色前薄片，厚 4 mm。
- `Z = 1048 mm` 的蓝色后薄片，厚 4 mm，和前片在像面上重叠。

薄片使用真实的 AABB 求交，不是贴图叠加，因此左右眼看到的前后遮挡边界会
随视点改变。

## 几何与深度反演

对眼中心 `e = (±IPD/2, 0, 0)`，世界点 `P = (X,Y,Z)` 的连续像坐标为：

```text
u = cx + f (X - e.x) / Z
v = cy - f Y / Z
```

左右像的水平视差和深度为：

```text
d = uL - uR = f * IPD / Z
Z = f * IPD / d
X = (uL - d/2 - cx) * Z / f
Y = (cy - v) * Z / f
```

投影中的 `-f e.x / Z` 就是随眼矩阵变化的投影偏移；它不能用一个与深度无关
的视口平移代替。`camera.go` 中正确路径和故障路径是分开的。

例如 72 mm 的正确左眼在前片深度和后墙深度处的投影偏移分别是
`+24.70 px` 和 `+12.48 px`；故障版在 1000 mm 参考面伪造 `+18.72 px`，
并在所有深度保持不变。每档 IPD 的这四个偏移值都记录在 `report.json` 的
`projection_offsets` 中。

立体匹配使用 5×5 RGB 块代价、抛物线亚像素细化、左右一致性检查和中值
离群过滤。搜索区间限制在场景的 600–1600 mm 深度范围内。深度图中的黑色
深度像素表示被遮挡、越界或无一致匹配；越近越亮，越远越暗。

## 故障版本

`ViewportOnly` 相机故意保留两个相同的原点眼矩阵，只按请求的 IPD 平移
投影视口。参考深度固定为 1000 mm，所以图像看起来仍有视差，但该视差是：

```text
d = f * IPD / 1000
```

它与物体的真实深度无关。所有有效像素都会被恢复成约 1000 mm，前后顺序
消失；中心射线仍从原点出发，却不再经过应有的 `±IPD/2` 眼中心；视口平移
还会让图像边缘出现洋红越界像素。

`report.json` 的 `failure_checks` 给出以下对照：

| 检查 | 正确版本 | 故障版本 |
| --- | --- | --- |
| 深度排序 | 前片约 758 mm，小于后片约 1047 mm | 两者都约 1000 mm |
| 中心射线 | 眼中心误差 0 mm | 误差 36 mm（72 mm IPD） |
| 越界像素 | 0 | 13680 个洋红像素 |
| 遮挡变化 | 后片左右可见面积差随 IPD 增大 | 左右眼可见面积完全相同 |

## 最新结果

三档同步相机的结果（误差是恢复深度相对解析射线深度的绝对误差）：

| IPD | 有效像素 | 中位误差 | P95 误差 | 后片遮挡面积差 |
| ---: | ---: | ---: | ---: | ---: |
| 55 mm | 92.3% | 2.77 mm | 12.77 mm | 880 px |
| 64 mm | 91.2% | 3.74 mm | 13.85 mm | 1056 px |
| 72 mm | 90.9% | 1.91 mm | 9.51 mm | 1232 px |

探针核对还会给出前片、后片、球面和前墙标尺点的解析交点、期望视差、恢复
视差以及三维位置误差。`artifacts/report.json` 中同时包含逐像素误差、
探针坐标和故障检查详情。
