# 20261124 — 立体双层遮挡剔除（纯 Go 标准库）

厚墙由双眼共享，细柱与透明片往往只遮挡单眼。本实现把遮挡查询分为
**共享遮挡集合** 与 **单眼补集** 两层，并记录共享遍历量、补集遍历量、
保守回退量与误剔除率。零外部依赖（`go.mod` 无任何 require）。

## 两层查询设计

- **共享层（厚墙）**：物体必须在左眼和右眼分别被墙体完全遮挡才允许剔除，
  对双眼保守。若共享结果排除了任一眼实际可见的物体，`Validate` 会将该帧
  判为 `shared_failure`（失败）。
- **补集层（细柱 / 透明片）**：逐眼评估。遮挡体只部分覆盖物体时视为
  单眼特有遮挡失效，立即扩大查询范围（按半径步进 0.5 最多扩展 3 次）
  重试；仍无法完全覆盖则保守保留物体，并计入 `conservative_fallback`。

## 运行

```sh
go run .      # 生成 artifacts/ 并打印汇总
go test ./... # 保守性、失败检测、回退扩展三组测试
```

## 产物（artifacts/）

- `camera_path.jsonl` — 逐帧立体相机路径（双眼位姿）
- `query_log.jsonl` — 逐帧查询日志：共享/补集遍历量、回退量、误剔除、可见数
- `frame_left.png` / `frame_right.png` — 双眼渲染画面
- `frame_diff.png` — 双眼画面差（视差可视化，3 倍增益）

## 代码结构

- `vec.go` — 向量、射线与球/AABB 求交
- `scene.go` — 场景：物体球 + 墙/细柱/透明片三类遮挡体
- `camera.go` — 立体相机与环绕路径生成
- `cull.go` — 轮廓采样遮挡测试与遍历计数
- `query.go` — 两层查询流水线、真值校验、失败判定
- `render.go` — 软件光线投射渲染与画面差
- `main.go` — 流程编排、日志与汇总输出
