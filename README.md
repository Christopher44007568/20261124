深度/模板双机（主机、右机）双眼生命周期管理，纯 Go 标准库实现，零第三方依赖。

- 包：`depthlife/`，每台机器一个 `Manager`，左眼/右眼独立槽位与审计日志。
- 覆盖清除、加载、解析、遮罩、保存、落盘恢复与跨帧复用，状态机见 `docs/design.md`。
- 每个派生产物带眼别与附件标签，陈旧眼别数据由统一 `guard` 拒绝并记 `stale-eye` 事件。

```sh
go test ./... -race -cover   # 全量测试（含必测场景）
go run ./cmd/demo            # 生命周期演示
```
