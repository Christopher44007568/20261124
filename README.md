# 2:2 棋盘着色率与无周期重建

本项目实现一个棋盘着色率（checkerboard shading rate）管线：中心区域逐像素
着色，外围按 2:2 棋盘（2×2 方块交替写入）只着色一半像素，再用一个**无固定
棋盘周期**的边感知重建把省下的样本补回来。

纯 Go 实现，仅依赖标准库（`math`、`image`、`image/png` 等），无任何第三方依赖。

## 规则与失败条件

- 中心矩形内每个像素都逐像素着色（`checker/mask.go`）。
- 中心之外按 `((x/2)+(y/2))` 奇偶写入 2×2 棋盘块，恰好 1/2 外围像素被着色。
- 重建只能写入未着色的外围像素；已着色像素与中心像素被锁定，逐位保持不变。
- 重建结果不得出现与 2:2 采样格点锁定的固定周期。
- 中心误用外围规则、或重建出现固定棋盘周期，均判失败。

## 重建方法（`checker/reconstruct.go`）

1. **边导向初始填充**：对每个缺失像素取 5×5 内已着色样本，按逆距离与边停止
   权重（基于 Rec.709 亮度差的高斯核）做全 RGB 加权，权重由亮度梯度决定、
   作用于三个通道，从而在保护边缘的同时不偏染色相。
2. **强边软聚类**：当邻域亮度明显分裂为明暗两簇时，按距离加权投票选边、平局
   由最近样本对的几何方向决定，避免跨越硬棋盘边界做灰度平均。
3. **坐标哈希破简并**：仅在局部平坦区对完全对称的退化情形施加按像素坐标哈希
   的微小抖动，打破任何会与棋盘格对齐的平局规律。
4. **交替方向边感知扩散**：多轮 Gauss-Seidel 扩散，每轮换扫描方向，中心与已
   着色像素始终锁定。整个过程确定性、可复现，且不含任何固定周期项。

## 无周期判据（`checker/metrics.go`）

- `PhaseDelta`：用互补的两个棋盘相位分别重建，求结果平均亮度差。固定棋盘
   伪影会随相位翻转符号而放大该值；内容驱动的重建对相位不敏感。这是主判据。
- `PeriodAC`：重建误差在棋盘块周期位移 `(4,0)`、`(0,4)` 上的归一化自相关。
   固定周期重建趋近 1，无周期重建趋近 0（平滑解析场景的高自相关只是自然平滑
   结构，由 `PhaseDelta` 区分）。
- `CheckerEnergy`：误差与零均值棋盘符号的归一化相关，配合自相关交叉验证。
- 测试中还构造了一个合成的固定棋盘周期误差，断言所有探针都能抓到它，防止
   探针本身失效；同时断言朴素“最近邻复制”基线必然被周期门判失败。

## 检查场景（`checker/scenes.go`、`scenes2.go`）

| 场景 | 类型 | 考察点 |
| --- | --- | --- |
| `analytic_blob` | 良定 | 解析径向/正弦图案的亮度与覆盖 |
| `procedural_fbm` | 良定 | 程序值噪声纹理的细节与色相 |
| `thin_diagonal_lines` | 良定 | 一像素细斜线的覆盖与抗涂抹 |
| `checker_16px` | 良定 | 高对比棋盘的边缘与覆盖 |
| `hue_sweep` | 良定 | 连续色相扫描的色相误差 |
| `checker_8px_aliased` | 别名 | 与 2:2 采样共振，只强制无周期 |
| `checker_2px_aliased` / `checker_1px_aliased` | 别名 | 低于/等于采样周期，单帧信息不可恢复 |

别名场景在数学上无法从单帧完整恢复（采样定理），因此只要求不伪造固定棋盘
周期、且中心保持精确；良定场景则同时约束亮度 RMSE/MAE、色相 MAE、覆盖
MAE/Dice 与归一化偏置（见 `checker/quality_test.go`）。

## 运行

```bash
go test ./...            # 全部门：掩膜比例、中心锁定、无周期、质量、确定性
go run ./cmd/demo        # 打印各场景指标
go run ./cmd/demo --out out   # 额外导出 truth/shaded/recon/mask PNG
```

演示输出列含义：`lumaRMSE/lumaMAE` 亮度误差，`hueMAE` 色相角误差（弧度），
`covMAE/dice` 覆盖误差与重叠度，`periodAC` 块周期自相关，`phaseΔ` 互补相位
重建差（主无周期判据）。

## 代码结构

- `checker/image.go`：浮点 RGB、亮度、色相。
- `checker/mask.go`：中心逐像素 + 外围 2:2 棋盘掩膜与着色。
- `checker/reconstruct.go`：边导向填充、强边聚类、哈希破简并、交替扩散。
- `checker/scenes.go`、`checker/scenes2.go`：分析/程序/斜线/棋盘/色相场景。
- `checker/metrics.go`：误差度量、周期探针、朴素失败基线。
- `checker/encode.go`：标准库 PNG 编码。
- `cmd/demo`：指标与图像导出的命令行入口。
