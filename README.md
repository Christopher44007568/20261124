# 自动曝光直方图更新策略对比

本仓库用 Go 复现自动曝光（AE）中“上一帧亮部污染当前帧统计”的问题，并对比以下三种测光方式：

- `whole-frame`：仅用当前帧的整帧亮度均值。
- `zonal`：将画面划分为 `12x8` 分区，用分区均值的中位数作为控制量，可抑制局部高光。
- `temporal-window`：使用最近 4 帧直方图合并后的均值；场景切变时立即清空窗口。

核心约束：`Frame.SceneCut` 表示亮度突变后的第一帧。分区测光器在该帧递增 generation、清空所有旧分区，并只用当前帧重新填充；任何旧 generation 的分区都不会参与统计。`Measurement.StaleZoneReads` 和汇总 CSV 会记录旧分区读取次数，测试要求始终为 0。

## 实验模型

- 帧尺寸 `96x72`，亮度范围 `[0,1]`，直方图 64 档。
- 初始中灰 `0.40`，目标亮度 `0.18`，初始曝光 `log2(0.18/0.40) ≈ -1.152 EV`。
- 控制器每帧执行 `EV += 0.5 * log2(target/measured)`，单帧最大调整 `1 EV`。
- 每条序列 40 帧，第 8 帧发生突变；闪光在第 10 帧熄灭并再次标记场景切变。
- `black-field`：中灰突变为 `0.02` 黑场。
- `white-field`：中灰突变为 `0.95` 白场。
- `flash`：两帧全白闪光后恢复中灰。
- `local-highlight`：约 8.6% 面积的 `1.0` 高光块持续出现，其余仍为中灰。

## 指标

- 曝光响应：逐帧记录当前 EV、测光控制量、帧均值、高光占比和时间窗长度。
- 收敛帧数：从最终亮度突变帧起，首次进入最终 EV 的 `±0.06 EV` 容差并保持的首帧；计数包含突变帧，`-1` 表示未收敛。
- 过冲量：在调整方向上越过最终 EV 的最大距离，同时记录峰值偏离 `PeakExcursionEV` 与相对步长的百分比。
- 旧分区读取：通过分区 generation 检查统计，正常路径必须为 0。

## 复现

```bash
go test ./...
go run ./cmd/ae-sim -out artifacts
```

输出文件：

- `artifacts/exposure_response.csv`：12 组“场景 × 策略”的逐帧响应。
- `artifacts/summary.csv`：收敛帧数、过冲、峰值偏离和旧分区读取次数。
- `artifacts/report.md`：Markdown 对比表。

## 解读

- 局部高亮下，整帧均值被高光块拉高，曝光下压约 `0.17 EV`；分区中位数直接忽略该局部区域，首帧即保持原曝光。
- 黑场和白场整帧阶跃中，整帧与分区均无过冲；时间窗虽然切变首帧不读取旧场景，但新场景内混合了不同曝光下的历史帧，响应滞后并产生 `0.54–0.66 EV` 过冲。
- 闪光恢复时，时间窗的过冲为 `0.33 EV`，整帧/分区无过冲；这是平滑历史与快速响应之间的直接取舍。
- 全部 12 组轨迹的 `stale_zone_reads` 均为 0，切变后第一帧只使用当前帧分区。

本实验使用确定性合成序列，便于回归比较；真实相机接入时可将 `Frame.Luma` 替换为下采样亮度平面，并保留 `SceneCut`/generation 失效规则。
