# 头部姿态时序实验（Go 标准库）

复现 “scanout 晚于姿态提交” 时的重投影问题：姿态在 `t` 提交，但左右眼图像分别在
更晚的时刻扫描输出，若仍按提交时刻的旧姿态渲染，两只眼的世界会一前一后地漂。

本程序用确定性的合成数据比较三种预测策略，全程只使用 Go 标准库。

## 时序模型

- 头部轨迹采样率：1000 Hz，每 1 ms 一个 yaw 样本（单自由度偏航角，弧度）。
- 每眼显示偏移均为 11 ms，按顺序扫描输出建模：
  - 左眼 scanout 时刻 = 提交时刻 + 11 ms
  - 右眼 scanout 时刻 = 提交时刻 + 22 ms
- 预测目标始终是 scanout 时刻；真值由连续轨迹函数在该时刻直接给出。
- 历史窗口 100 ms；预测最远允许领先最新样本 50 ms（horizon）。
- 角速度由样本差分做指数滑动平均（EMA，时间常数 8 ms），避免对 1 kHz 量化噪声做理想微分。

## 三种预测模式

- `zoh`：零阶保持，直接复用最新 yaw，不做任何旋转外推。
- `velocity`：用 EMA 角速度按目标时间差线性外推。
- `clamped`：与 `velocity` 相同，但把角速度限幅到 `±6 rad/s`，用于抑制急停后的超调。

## 场景

- `estop`：以 10 rad/s 匀速转到 1.0 s 后瞬间冻结（急停）。
- `constant`：全程 10 rad/s 匀速转头。
- `sine`：`0.8 * sin(2*pi*t/1s)` 的正弦轨迹，峰值角速度约 5.03 rad/s。
- `drop`：同一条正弦轨迹，按固定时刻表丢帧（12/16/24/80/10 ms 五段间隙）。

每个场景都在 300 ms 注入两类无效样本（时间戳回退、NaN yaw）和一次落在历史窗口
之外的无效查询；`drop` 场景的 80 ms 长间隙还会让右眼查询超出 50 ms horizon。

## 无效时间戳规则

样本（`AddSample`）被拒绝的情形：

- yaw 为 NaN/Inf：`nan_yaw`
- 时间戳早于历史窗口下界：`before_history_window`
- 时间戳重复或回退（非单调）：`timestamp_rolled_back`

查询（`PredictAt`）被拒绝的情形：

- 尚无任何样本：`no_samples`
- 目标时刻早于历史窗口下界：`before_history_window`
- 目标领先最新样本超过 horizon：`beyond_prediction_horizon`

所有拒绝都带场景、模式、样本/查询类型、发生时刻与原因，写入 `rejects.csv`，
被拒绝的查询不会产生预测记录。

## 运行

```sh
go test ./...
go run . -out out
```

程序无随机数、无外部依赖，重复运行得到完全一致的结果。

## 输出文件

- `out/records.csv`：每条被接受的逐眼预测，含真值、预测值、绝对/带符号误差、超调和丢帧年龄。
- `out/rejects.csv`：每条被拒绝的样本或查询及其原因。
- `out/summary.csv`：每个 场景 × 模式 × 眼 的均值、RMSE、最大误差、最大超调（弧度与度）。
- `out/summary.txt`：人类可读的对比表。

误差均先归一化到 `[-pi, pi)`；超调定义为带符号误差在运动方向上的正向分量，
反向滞后记 0，因此零阶保持在匀速段只有滞后、没有超调。

## 典型结论（以 `summary.txt` 为准）

- 匀速 10 rad/s 时，零阶保持的固定滞后为 `omega * offset`：左眼 6.30°、右眼 12.61°，
  右眼误差约为左眼两倍，直接对应“双眼一前一后地漂”。
- 角速度外推在匀速/正弦段把误差压到接近零，但急停后因 EMA 仍带旧速度，
  产生峰值约 12.6°（右眼）的超调。
- 限幅外推把急停超调峰值减半左右，代价是快速匀速段重新出现约 2.5°/5.1° 的滞后。
- 正弦峰值角速度低于限幅值，因此 `velocity` 与 `clamped` 在正弦/丢帧场景一致；
  丢帧期间误差随 `gap_age` 增长，80 ms 长间隙的右眼查询被 horizon 拒绝。

## 代码结构

- `angle.go`：角度归一化、度弧度换算、限幅。
- `predictor.go`：历史缓冲、EMA 角速度、三种模式与时间戳校验。
- `trajectory.go`：四条合成轨迹的解析真值。
- `experiment.go`：逐毫秒仿真、故障注入、丢帧与统计。
- `report.go`：CSV 与文本报告。
- `main.go`：入口。
- `*_test.go`：单元测试与关键行为回归测试。
