## 畸变后处理网格对比实验（纯 Go，无图形 SDK）

对比三种畸变校正网格生成策略，记录顶点位置、最大几何误差、
插值空洞与耗时：

- `uniform`：均匀网格
- `radius`：按半径加密（坐标 warp `p(t)=t*(1+a-a*t²)`，边缘更密）
- `adaptive`：弦高误差自适应四叉树加密，T 型结点扇形缝合

畸变模型 = 宽视野径向畸变 + 局部高斯突变（`distortion.go`）。
所有策略边界固定 `[-1,1]²`，加密不改变显示边界，低密度区保守覆盖。

运行：

```
go run .
```

输出：终端对比表 + `artifacts/*_vertices.csv`（顶点位置）+
`artifacts/summary.csv`（汇总指标）。
