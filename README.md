# 重投影与镜头畸变顺序实验

本仓库只使用 Go 标准库，比较两种两级处理顺序：

- `reproject-then-distort`：先把带深度的源像素重投影到目标相机，再施加目标镜头畸变。
- `distort-then-reproject`：先在源相机图像上施加畸变，再把畸变后的像素和深度重投影。

两条管线都使用确定性最近邻前向散射和深度测试，因此每一级的采样读取、写出、越界、遮挡与空洞都可重复统计。畸变采用高曲率径向项和非对称切向项；场景包含左侧近景、右侧远景和底部中景物体，它们都接触屏幕边缘。

## 结论

测试选择 `reproject-then-distort`。在当前参数下：

| 顺序 | 重采样级数 | 源采样读取 | 写出 | 空洞 | 连续参考颜色 RMSE | 连续参考深度 RMSE |
|---|---:|---:|---:|---:|---:|---:|
| 先重投影再畸变 | 2 | 310003 | 255831 | 54172 (31.350%) | 15.72408 | 0.15399 |
| 先畸变再重投影 | 2 | 320247 | 271993 | 48254 (27.925%) | 32.21887 | 0.22260 |

注意：第二种顺序的空洞更少、部分探针也更容易被覆盖，但它相对“连续坐标一次组合、一次栅格化”的参考颜色和深度误差几乎翻倍。因此选序首先比较参考几何误差，空洞数、覆盖和重采样量只作为后续平局判据。截图接近或像素更“满”不能改变顺序。

参考图不是截图匹配，而是把两级坐标映射先连续组合成
`distort(reproject(source))`，然后只做一次栅格化。测试固定要求先重投影序更接近该参考。

## 测试

```bash
go test -v ./...
go vet ./...
```

测试覆盖：

- 高曲率畸变、较大平移和三个屏幕边缘物体的两序对比。
- 顺序选择必须由参考颜色/深度误差决定；即使后畸变序空洞更少也不能交换。
- 低分辨率畸变后重投影：记录额外空洞、较少写入和更差深度误差。
- 逐通道畸变：R/G/B 使用略有差异的畸变系数，检查边缘色移和不同通道空洞。
- 错误复用深度：颜色已畸变但仍配对旧深度，要求颜色/深度探针和最大深度误差都能拒绝。

## 生成报告

```bash
go run ./cmd/reprojlab -out artifacts/orderlab
```

产物：

- `report.json`：机器可读的分级重采样计数、空洞、深度坐标探针和故障变体指标。
- `report.md`：同一结论的表格摘要。
- `source.png`、`reference.png`、两种顺序输出、低分辨率输出、错误深度输出和逐通道输出。
- `depth-*.png`：参考及两种顺序的深度可视化。

PNG 仅辅助观察，选序测试不读取图像，也不使用截图相似度。

## 代码结构

- `geometry.go`：针孔投影、径向/切向畸变、带深度重投影。
- `raster.go`：栅格、前向散射、深度测试及分级计数。
- `scene.go`：程序化边缘深度场景和连续组合参考。
- `pipeline.go`：两种顺序、低分辨率变体、旧深度变体和逐级探针追踪。
- `metrics.go`：栅格误差和选序规则。
- `variants.go`：逐通道畸变。
- `order_test.go`：顺序及故障变体测试。
- `report.go`、`artifacts.go`、`markdown.go`：JSON、PNG、Markdown 产物。
- `cmd/reprojlab`：报告命令。
