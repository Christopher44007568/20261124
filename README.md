# 20261124 — 双眼 HZB 遮挡剔除（纯 Go，零外部依赖）

**问题**：双眼能否复用同一张 HZB？答案是可以部分复用——小幅旋转/瞳距下远层（粗 mip）几乎一致（实测失配单元 0%），近层（细 mip）因视差失效（实测失配 14%）。因此：

- 左右眼各自构建独立深度金字塔（`hzb.Pyramid`）；
- 远层（`>= SharedFromLevel`）跨眼共享，近层逐眼重建（`BuildStereo` / `ReuseFarLevels`）；
- 凡由共享层、过期层或粗层给出的"剔除"判定，先经保守重放（`Recheck`：沿本眼近层逐级下降，必要时对 mip0 做逐像素光栅复核）才生效——重放只会把"剔除"翻成"可见"，绝不反向，因此保守。

## 统计与溯源

`hzb.Stats`：复用率（共享单元/总单元、共享层查询占比）、误剔除数与误剔除像素、保守重放次数/挽回次数/扫描像素、构建与查询耗时。
每个误剔除记录为 `hzb.FalseCullEvent`，包含对象、眼（相机 ID）、判定帧、判定层级与单元格、以及**产生该层的相机与帧号**，可精确定位旧层。

## 覆盖场景（`hzb/stereo_test.go`）

- 薄杆：max-pooling 膨胀导致误剔除，重放修复；
- 遮挡揭示：相机平移后目标露出，过期远层误剔除并可溯源到旧帧；
- 不同近面：近面不一致判定为不兼容，自动退回逐眼完整金字塔；
- 历史帧不匹配：旋转后旧帧远层误剔除，事件含旧层相机与帧号；
- 小幅旋转：量化验证远层对齐度远高于近层。
