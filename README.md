# 立体重投影校验器（stereoval）

纯 Go（仅标准库）实现的双目重投影质量校验工具。不依赖任何图形 SDK：
场景由自带的软件光栅器绘制，重投影、补洞、指标计算全部是普通 Go 循环。

## 要回答的问题

左右两张重投影图各自“看起来正常”，并不代表双眼之间的空间关系仍然正确。
本工具用**已知深度的标记**和一条**连续相机路径**，对每个时间戳同时记录：

- 每眼重投影误差（以同帧真值标记质心为基准，分眼 RMS / P95 / 最大）
- 视差误差与帧间视差变化（观测视差 vs 由已知深度解析得到的真值视差）
- 鬼影比例（强边缘上的结构性强度冲突；补洞区域单独统计补洞鬼影）
- 边缘错位（Sobel 边缘 + Chamfer 距离场，有向与对称两种）
- 空洞比例与跨眼补洞比例，以及落在补洞/空洞上的受污染标记数

## 四个独立测试的策略

1. `healthy`：每帧用当前姿态版本，把上一帧历史反向 warp 到当前几何。
2. `reject_history`：右眼周期性拒绝历史（无可用历史 → 整片空洞），
   左眼保持正常，验证缺陷能按单眼定位、不会被健眼掩盖。
3. `cross_eye_fill`：更大横向运动制造去遮挡带，空洞由另一眼的历史视角
   采样填补且**不做逐眼视差校正**，用于暴露补洞鬼影与视差污染。
4. `pose_version_skew`：左眼用当前姿态版本、右眼用两帧前的旧版本，
   制造双眼姿态版本不一致。

## 判定规则

单眼指标与跨眼视差指标是**相互独立的门限**。即使 pooled 平均重投影误差
合格，只要视差 RMS / P95 或视差帧间变化越线，整个 run 仍判失败
（见 `internal/harness` 的 `TestDisparityGateIndependentOfAverage`）。
稳健统计使用 P95 而非硬最大值，避免单个边界像素噪声主导结论；原始最大
值仍写入报告供排查。

## 目录结构

- `internal/geo`：向量/矩阵、针孔相机投影与反投影、立体 rig、连续路径
- `internal/scene`：不同深度面板与带已知世界坐标的标记
- `internal/render`：z-buffer 软光栅、亚像素标记、反向 warp、跨眼补洞、PGM 导出
- `internal/metrics`：标记质心、Sobel/Chamfer 边缘、鬼影、统计助手
- `internal/harness`：四种场景策略、逐帧评估、聚合与判定
- `cmd/stereoval`：命令行入口与 JSON 报告

## 运行

```bash
go test ./...          # 单元测试与四场景判定契约
go run ./cmd/stereoval # 生成 artifacts/reports/*.json，控制台打印摘要
go run ./cmd/stereoval --dump  # 额外导出首帧 PGM 便于人工查看
```

退出码：所有策略可接受时为 0；任一策略被拒绝时为 1。
