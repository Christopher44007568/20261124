# 旋转 timewarp vs 深度平移重投影

同一张带深度的源帧，分别走两条单帧 timewarp 路径：

- **纯旋转 warp**：只用两个相机姿态的相对旋转，不读深度、不写深度。
- **深度平移重投影**：按源深度把每个像素投影到目标相机，前向 z-buffer 解决遮挡，缺深度和无覆盖区域保留为拒绝孔。

报告并排检查 **快速转头** 与 **头部前移**，并把 **房间、近杆、静止高光**、拒绝掩码、误差热图和越界采样分开统计。

## 快速开始

```sh
go run ./cmd/timewarp -out out
xdg-open out/report.html
```

也可以起一个只依赖标准库的本地静态服务：

```sh
go run ./cmd/timewarp -out out -serve :8080
```

`go.mod` 没有 `require`，运行和测试均只使用 Go 标准库。

## 结果

默认 `640×360`、FOV-Y `52°`、前移 `0.68` 世界单位、转头 `yaw +12° / pitch -2°`。

| 场景 | 方法 | 覆盖 | 整帧 MAE | 近杆 MAE | 静止高光 MAE | 越界采样 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| 快速转头 | 纯旋转 | 78.1% | 1.46 | 0.38 | 1.02 | 50,406 拒绝 |
| 快速转头 | 深度重投影 | 77.4% | 1.83 | 0.60 | 3.25 | 0 |
| 头部前移 | 纯旋转 | 100% | 22.26 | 65.57 | 48.69 | 0 |
| 头部前移 | 深度重投影 | 89.3% | 2.36 | 3.38 | 4.49 | 0 |

MAE 为 0–255 通道均值。前移时纯旋转画面完全不产生视差，近杆与静止高光误差明显；深度路径把近杆放大并横移，背景和世界锚定高光跟随正确几何。转头时旋转路径几乎精确贴合，深度路径额外承担遮挡/缺深度/边缘覆盖问题。

## 产物

`out/report.html` 为离线报告，包含：

- 目标真值 / 纯旋转 / 深度重投影三列并排；
- 语义区域图、两种方法的拒绝掩码、误差热图；
- 整帧与 room / near pole / static specular 分区指标；
- 近杆与静止高光的像素级放大三联图；
- `out/metrics.json` 机器可读指标。

## 关键约束

- 旋转路径的 `DepthValid` 输出恒为 `false`，不会伪造深度，也不能借此做遮挡判断。
- 旋转路径对源坐标做严格帧内检查，出界直接记 `out_of_bounds`，不 clamp、不 wrap。
- 深度路径没有源深度的像素不投影；目标空洞写进拒绝掩码，不用边界像素补洞。
- 深度路径所有颜色采样都先检查源帧范围；越界计数保持 0。源像素本身投影到目标画面外时单独计入 `source_offscreen`。
- 合成场景中右上背墙有一块“有颜色、无深度”的 dropout 区，用来验证缺深度不会越界补采。

## 目录

- `cmd/timewarp`：生成报告、打印摘要、可选 HTTP 服务。
- `geom`：向量、旋转、针孔相机与逆投影。
- `scene`：解析式房间、近杆、世界锚定高光、缺失深度补丁。
- `warp`：纯旋转映射与带深度前向 z-buffer 重投影。
- `metrics`：整帧/分区 MAE、RMSE、覆盖率和坏像素率。
- `report`：PNG 掩码/热图/放大图、`metrics.json`、`report.html`。
