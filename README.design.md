# 姿态定长历史缓冲与重采样

纯 Go 标准库实现，无第三方依赖。模块路径 `posebuffer`。

## 目录

- `pose/pose.go`：时间戳类型、平移线性插值、四元数 Slerp 与角误差
- `pose/buffer.go`：定长环形缓冲、乱序插入、重复覆盖、回退处理、统计
- `pose/query.go`：最近邻查询与历史重采样查询（含超窗/缺口状态）
- `pose/hub.go`：时钟域注册表，不同时钟物理隔离
- `cmd/poseeval/`：120 Hz 相机查询下的三方误差评估程序

## 设计要点

**定长环形缓冲**：容量固定，内存有上界。样本按时间戳排序存放，乱序到达
仍保持有序；容量耗尽时，正常样本淘汰最旧者，早于最旧样本的回退样本淘汰
最新者。重复时间戳原地覆盖，不增长缓冲。

**时钟回退**：新样本时间戳早于已缓存最新样本即计入 `ClockRollbacks`，并触发
可选回调；样本仍按时间顺序插入而不是被丢弃。

**短缺口与超窗**：相邻样本间距超过 `MaxGap` 时拒绝插值并返回
`StatusGapTooLarge`；查询超出最早/最晚样本且超过 `Extrapolate` 预算时返回
`StatusBeforeWindow`/`StatusAfterWindow`，绝不静默返回陈旧姿态。预算内的
外推保持最后一条样本（零阶保持），避免基于两点速度估计的发散。

**平移与四元数分别重采样**：平移用分量线性插值 `Lerp`；旋转用恒角速度球面
线性插值 `Slerp`（短弧、单位化、近重合时退化为归一化线性插值）。角误差用
测地角 `AngleBetween`。

**时钟域隔离**：`Hub` 为每个 `Domain` 维护独立 `Buffer`，域之间没有任何
时间戳换算或数据借用；未知域查询返回 `StatusEmpty`。

## 评估场景

相机以 120 Hz（8.333 ms）查询；输入为 90/120 Hz 混合流（±1 ms 抖动），
仿真 4 秒。场景包括：基线、重复样本、200 ms 连续丢包、连续三帧乱序、
时钟回退、全部压力叠加。每个场景并列三种估计：

- `nearest_neighbor`：不重采样，取时间距离最近的样本
- `history_resample`：平移 Lerp + 四元数 Slerp
- `analytic_truth`：解析真值轨迹，误差恒为零，作为参照行

指标为位置 RMSE/最大值（米）与旋转 RMSE/最大值（弧度）。

## 运行

```sh
go test ./...
go run ./cmd/poseeval
```

典型结论：基线与乱序场景下历史重采样的 RMSE 比最近邻低约一个数量级；
200 ms 丢包期间最近邻仍可返回陈旧值但最大误差显著放大，重采样则对
25 个落窗查询明确返回不可用状态而不是虚构数据。
