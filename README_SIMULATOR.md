# Stencil × Scissor 联动裁剪复现器（Go 标准库）

纯软件光栅化模拟器，逐像素记录模板值、scissor 裁剪判定与最终颜色，对比参考实现与注入缺陷的实现，定位首个错误像素及其完整状态序列。

## 运行

```bash
go test ./...
go run .
```

报告输出到 `artifacts/reports/`：

- `S1_window_move.md` … `S5_*.md`：每场景的帧缓冲地图、首个错误像素、参考/缺陷两侧逐指令状态序列
- `*_bug.csv`：缺陷帧逐像素的模板值与颜色，便于离线 diff
- `summary.txt`：五场景汇总

## 场景与缺陷注入

同一套嵌套面板 UI（外层 → 内层 → 装饰面板 + 页脚），包含反向模板操作
（`INCR_CLAMP` 1→2 后 `DECR_CLAMP` 2→1）与空 scissor 矩形（`W=0`）。

| 场景 | 注入缺陷 | 现象 |
|---|---|---|
| S1 | 窗口移动后 scissor 仍叠加旧窗口偏移 | 面板左上区域被错误裁掉 |
| S2 | DPI 1→2 后仍按旧比例映射矩形 | 物理坐标错位，大面积误裁 |
| S3 | 空 scissor 矩形被忽略、未入栈 | 同步点泄漏，装饰面板被错误重绘 |
| S4 | 清空前残留 scissor 未解除 | 清空只作用于局部区域，其余像素未初始化 |
| S5 | scissor 与模板引用同帧变化，引用沿用缓存旧值 | 模板测试失配，装饰面板颜色/模板错误 |

## 关键语义

- scissor 维护逻辑矩形栈，`PUSH` 取与栈顶的交集；空矩形正确语义是入栈后任何像素都不通过
- 模板比较支持 `ALWAYS/NEVER/EQUAL/...`，写回受 `WriteMask` 限制，递增/递减钳制在 0–255
- 参考实现的 `CLEAR` 不受 scissor 限制（模拟 `D3D11_CLEAR_DEPTH|STENCIL` / `glClear` 在禁用裁剪位时的语义）
- 行优先（y 从小到大）扫描第一个颜色或模板不一致的像素作为首个错误像素
- 每个像素的每条指令都记录：逻辑/物理裁剪矩形、scissor 判定、模板函数与引用、模板判定、模板前后值、颜色前后值
