# cullsim — 单眼遮挡揭示与三种剔除策略对比（Go，零外部依赖）

模拟快速转头时“上一帧双眼并集缺少下一帧露出物体”的问题，并对比三种
候选剔除策略。仅使用 Go 标准库（`image/png` 出图，内置 5x7 点阵字体）。

## 场景

- 三层嵌套方形房间，每面墙带门洞（`ringWalls`），外加 6 段近墙隔板，
  使双眼 9 单位瞳距产生显著的单眼遮挡差异。
- 240 个静态物体散布在可走行环带内。
- 移动光源沿观察者走行环带附近摆动（角向超前/滞后 + 径向抖动），
  物体只有被光源照亮（半径内且光线不被墙遮挡）才需要绘制。
- 观察者沿环形路径行走，偏航角 = 切向 + 慢速扫视 + 两段快速转头突发
  （峰值约 25°/帧）。

## 管线模型（关键假设）

取候选集需要一帧时间：策略只能使用**上一帧及更早**的位姿信息，
而地面真值（`Required`）在**当前显示位姿**上评估。快速转头时查询
天然滞后一帧——这正是三种策略的分水岭。

## 三种策略

- `none`（无预测）：直接用上一帧实测位姿做视锥查询。
- `union`（共享并集）：复用上一帧双眼确认可见物体集合的并集，
  候选数最少，但转头时整片漏绘。
- `predict`（路径预测）：由最近两帧位姿线性外推显示位姿，取
  “上一帧位姿锥 ∪ 预测位姿锥”的扫掠体，并加自适应余量。
  **预测失效（出现漏绘）后下一次查询自动扩大**角余量与距离余量
  （×1.7 + 固定步长，封顶 45°/120）；连续干净帧则按 0.92 衰减回最小值。

## 指标与“空洞不是背景”

每帧每策略记录：候选数、实际绘制数、漏绘（在真值中但不在候选中）、
多绘（在候选中但不在真值中）。帧快照中漏绘物体用品红圆点 + 圆环 +
十字标出（图例 `MISS HOLE NOT BG`），绝不画成背景色。

## 运行

```sh
go build -o cullsim . && ./cullsim -out ../artifacts
go test ./...
```

产物（写入 `-out` 目录）：

- `metrics.csv` — 逐帧逐策略的候选/绘制/漏绘/多绘。
- `metrics.png` — 三面板曲线图（候选数、漏绘、多绘）。
- `frame_NNN_<strategy>.png` — 在共享并集策略漏绘的代表帧上，
  三种策略各自的俯视最终画面。

典型结果（90 帧）：`union` 漏绘约 195 个（39 帧出现空洞）但候选最少；
`none` 漏绘 8 个；`predict` 仅漏绘 1 个（第 23 帧触发自动扩围后归零），
代价是多绘高于 `none`。
